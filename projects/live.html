이야기 2 · 라이브 방송 · 메타버스엔터테인먼트(주)

라이브 리타게팅 시스템

한눈에 보기

  • 방송 전 촬영 준비 시간 2시간 30분 → 30분 (연기자 4명 기준)
  • 연기자 1명당 30분 이상 → 5분
  • 편집한 설정이 저장되어, 방송할수록 품질이 쌓임
전에는
2시간 30분

촬영할 때마다 연기자의 몸 정보가 새로 만들어져, 현장에서 처음부터 다시 맞춰야 했습니다.

지금은
30분

미리 해둔 설정을 매번 그대로 이어받고, 쓸수록 캐릭터 움직임이 자연스러워집니다.

기간 · 소속2023.07 – 2025.03 · TA팀
쓰는 사람방송 현장 스태프
사용 도구Python, MotionBuilder

조금 더 자세히

배경

  • 모션캡처로 연기자의 움직임을 3D 캐릭터에 실시간으로 입히는 라이브 방송
  • 흐름: 연기자 → 3D 뼈대로 재구성 → 캐릭터 뼈대로 보정(담당) → 언리얼 엔진으로 실시간 송출
  • 현장 작업이 늦어지면 뒤쪽 작업과 방송이 모두 밀림

목적

  • 가능한 모든 것을 미리 준비해 현장 작업 최소화
  • 실시간 데이터 송출을 더 안전하게
  • 캐릭터의 더 정교하고 자연스러운 움직임

문제점

  • 연기자의 3D 뼈대는 촬영 때마다 새로 만들어져, 원칙적으로 미리 준비할 수 없음

해결

  • 매번 하던 뼈대 불러오기와 캐릭터 연결 작업을 자동화
  • 정해진 자세로 불러오고, 약간의 오차는 허용하며 자동으로 맞춤
  • ‘중간다리’ 뼈대에 미리 설정해 두고, 새 뼈대를 여기에 이어 붙여 설정을 계속 승계
  • 자세를 인식해, 기존에 어색하던 여러 동작도 자연스럽게 보정

결과

  • 4인 동시 촬영 준비 2시간 30분 → 30분
  • 설정을 저장·발전시킬 수 있어 품질이 지속적으로 개선
