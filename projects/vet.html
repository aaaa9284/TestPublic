이야기 1 · 동물병원 · 프리랜서

동물병원 보호자용 보고서 자동화

한눈에 보기

  • 보호자에게 드리는 보고서 작성 1시간 30분 → 15분
  • 손으로는 못 하던 검사 수치 그래프까지 자동으로 작성
  • 요구 파악, 설계, 개발(Claude), 설치·배포, 유지보수를 혼자 수행
  • 소요 기간 약 2.5개월 (2026.05.05 – 2026.07.21)
전에는
90분

검사 수치를 하나하나 옮겨 적고, 보고서에는 표만 있고 그래프가 없었습니다.

지금은
15분

결과를 넣으면 그래프까지 들어간 보고서가 자동으로 완성됩니다.

맡은 역할기획 · 개발 · 설치 · 유지보수 1인
쓰는 사람수의사 1명, 테크니션 3명
사용 도구Claude, Python

조금 더 자세히

고객 요구

  • 보호자용 보고서(PPT)를 가능한 한 자동화
  • 혈액 등 검사 결과를 그래프로 표시

병원 상황

  • 보고서 작성 때문에 수의사의 시간이 항상 부족
  • 초음파 사진에 구분 표시가 없어 보고서에 넣기 번거로움
  • 저사양 사무용 PC 2대
  • 기존 프로그램은 디자인이 아쉽고, 템플릿 변경이 안 되며, 그래프가 없음

기획

  • 업무 흐름: 테크니션이 사진 이름을 바꾸고 변환 프로그램 실행 → 수의사는 소견 작성과 초음파 사진 편집만
  • 매번 AI를 돌리지 않고, 완성된 프로그램이 혼자 실행되도록 설계 (설치는 파일 1회 실행)
  • 사진은 끌어다 놓으면 이름이 바뀌고, 보고서의 정해진 자리에 자동 배치
  • 병원이 언제든 디자인을 바꿀 수 있는 빈 템플릿 PPT 제공

개발

  • 병원에서 받은 실제 샘플 차트로 작업
  • Claude가 코드 작성 → 자동 디버깅 + 직접 검토·수정
  • 주요 개발은 상위 요금제, 이후 간단한 수정은 하위 요금제로 비용 조절

문제와 해결

  • 그래프 줄이 맞지 않음 → 맞을 때까지 수정
  • 그래프가 작다는 의견 → 코드 수정 없이 템플릿에서 조정
  • 일부 단위명 잘림 → 원인이 꼬인 구조임을 찾아 v2.0에서 정리
  • 병원 PC와 글꼴 불일치 → 같은 오피스 환경을 갖추고 글자 크기 지정 방식 수정
  • 검사 프로그램 언어가 예고 없이 바뀜 → 바뀐 결과에 맞춰 대응

결과

  • 수의사: 소견 작성과 초음파 편집에만 전념
  • 테크니션: 끌어다 놓기로 사진을 넣고, 수치를 손으로 고칠 필요가 없어짐
  • 최근값·직전값 그래프로 보고서 디자인도 만족
  • 템플릿 디자인은 병원이 직접 변경 가능
