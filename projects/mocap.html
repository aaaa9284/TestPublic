이야기 3 · 모션캡처 팀 · (주)시나몬

모션캡처 데이터 처리 자동화

한눈에 보기

  • 두 사람이 손으로 하던 일을 혼자서도 더 빨리, 더 정확히
  • 꼭 필요한 두세 단계를 빼고 모든 반복 과정을 자동화
  • 다른 사람 대비 절반 이하의 시간으로 처리
전에는
2명이 손으로

정해진 절차를 매번 사람이 반복했습니다.

지금은
1명이 자동으로

스크립트와 일괄 처리로, 사람은 꼭 필요한 판단만 합니다.

소속(주)시나몬 모션팀
작업 범위데이터 정리·변환 전 과정
사용 도구Claude, Python, MotionBuilder, Shogun

조금 더 자세히

배경

  • 촬영한 동작 데이터를 정리·변환해 다음 공정에 넘기는, 반복이 대부분인 업무
  • 3D 제작 과정의 맨 앞이라 빠른 처리가 필수
  • 같은 업무를 하던 동료가 입사 6개월쯤 후 퇴사

목적

  • 자동화할 수 있는 모든 것을 자동화해 시간 확보
  • 동료 퇴사 후 2인분을 혼자 처리

기획

  • 현재 업무 과정을 전부 나열 → 자동화 필요성과 가능성 평가
  • 시간이 가장 많이 들고 수고로운 부분부터 자동화
  • Claude를 최대한 활용하고, 필요한 부분만 직접 코딩

구현

  • 저장·내보내기 경로와 파일명을 정해, 다음 작업이 바로 이어받도록 구성
  • 자세를 분석해 움직임·회전 여부를 판별하고 알맞은 작업을 자동 수행
  • 수작업이 필요 없는 여러 스크립트를 하나로 묶어 실행
  • 여러 파일·여러 테이크 작업은 모두 일괄 처리

결과

  • 필수 수작업 두세 개와 실행 자체를 빼고 모두 자동화
  • 다른 사람 대비 절반 이하의 시간으로 더 정확한 작업
  • 퇴사할 때까지 업무 병목 없이 창의적인 작업에 집중
